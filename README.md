# Automatic-Identification-of-Visual-Resources-for-Creating-News-Values-in-Social-Media-News-Content
Данный репозиторий используется для хранения и демонстрации разработки экспериментальной модели автоматической классификации визуальных новостных ценностей на основе DNVA и ее апробации на визуальном контенте для социальных сетей.
